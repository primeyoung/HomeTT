# Full-Stack Implementation

1. Follow the repository's established framework, package manager, naming, formatting, and directory conventions.
2. Define data flow and API contracts before implementing tightly coupled frontend/backend changes.
3. Frontend: handle loading, empty, success, error, validation, responsive layout, accessibility, and keyboard behavior.
4. Backend: validate inputs, authenticate and authorize, handle errors consistently, log useful context, and avoid leaking secrets.
5. Database: use migrations, constraints, indexes, transactions, and safe rollback plans.
6. Add tests at the appropriate layer: unit, integration, contract, and end-to-end.
7. Keep components and modules cohesive; avoid giant components and unnecessary abstraction.
8. Verify real app behavior where browser tooling is available; inspect console and network errors.
9. Update API docs and project docs when behavior or contracts change.
