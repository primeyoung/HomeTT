# UI and UX Design

1. Understand target users, task frequency, platform, brand, and product context.
2. Define information hierarchy and primary user journeys before styling.
3. Establish typography, spacing, color, surfaces, states, and component conventions.
4. Design loading, empty, error, success, disabled, focus, hover, and validation states.
5. Ensure responsive behavior, keyboard access, semantic structure, contrast, and reduced-motion support.
6. Prefer consistent reusable components without over-generalizing.
7. Avoid generic template aesthetics; make visual choices purposeful and coherent.
8. Verify the rendered UI at realistic viewport sizes when browser tools are available.
9. Treat accessibility and performance as product requirements, not final polish.
